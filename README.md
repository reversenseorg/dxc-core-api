# Dexcalibur Core API

The core API defines very common constant for any Dexcalibur-based things.

It is an ultimate dependency for everey project and the place where the value of any NodeType is defined.



## Getting Started

Install from private NPM registry :  
```
npm i @dexcalibur/dxc-core-api
```

Then you can use it as follow where NodeType are required :
```
NodeInternalType.<NODE_TYPE>
```
